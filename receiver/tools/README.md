# CSI CSV 파일 설명

50hz 로 1초 50패킷이고 10초 수집함  
최대 500행 나옴 손실 존재함  
손실은 안테나 방향(금속판을 마주보면 더 잘나옴), 채널 혼잡 이 원인 아직모름.

`seq` — 패킷 번호  
보낼때 순서대로 바디에 담아 보냄,  
이걸로 손실됐는지 파악 가능.

`lost` — 지금까지 잃어버린 패킷 수 (누적)  
seq 보고 사라진 패킷 누적 계산

`ts_us` — 받은 시각 (마이크로초)  
부팅부터 마이크로초 단위로 시각을 잼

`rssi` — 신호 세기 (dBm)  


`len` — csi 값 개수  
csi 필드에 숫자 몇 개 들었는지, 지금은 항상 256

`csi` — 채널 상태 정보 원본  
숫자 256개를 공백으로 구분해서 한 칸에 넣음  
2개씩 묶어서 서브캐리어 1개 (허수부, 실수부 순서)  
앞 128개는 L-LTF, 뒤 128개는 HT-LTF (펌웨어에서 둘 다 켜고 따로 받게 해둠)  
각각 서브캐리어 64개, 순서는 0 ~ 31, -32 ~ -1    

의미 없는 값 위치 (값 위치는 0부터 셈)
- 0 ~ 3: ESP32 하드웨어 한계로 매번 같은 쓰레기값 (`47 -16 2 0`)
- 54 ~ 75: L-LTF 가드 (옆 채널이랑 안 겹치게 비워둔 자리, 항상 0)
- 128 ~ 129: HT-LTF DC (채널 한가운데라 안 씀, 항상 0)
- 186 ~ 199: HT-LTF 가드 (항상 0)
